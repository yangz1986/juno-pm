# Lovable Prototype · Juno

> Module 1 · Prompting. The clickable Lovable prototype that brings the system prompt to life.

## Prototype link

https://juno-pm-assist.lovable.app

## What it demonstrates

It is able to process all the interview transcripts, support tickets, executive emails and synthesise it into structured insight where it categorise it following the prioritisation of the issues and output a PRD back with evidence

## Debrief

- **What worked:** The overall UI experience works but the information display does not follow the real user-interview transcript after the process button is clicked
- **What broke / felt like a toy:** The Prototype did not display the information (structured insight & Opportunity brief) following the real user-interview transcript that was added into the Raw User Transcript section
- **What I'd change next pass:** I would ensure the next prototype will be able to ingest the new input in the Raw User Transcript section and correctly output the right issue prioritisation in structure insight & recommend the right opportunity solution in the Draft PRD/Opportunity Brief section
